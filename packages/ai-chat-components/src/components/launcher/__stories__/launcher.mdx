## Overview

The `cds-aichat-launcher` is a floating action button that opens and closes the AI Chat window.
It ships as a standalone web component so consumers can wire it to their own state management
, when the built-in launcher is removed in 2.0.

### Getting started

```html
<cds-aichat-launcher
  closed-label="Open chat"
  open-label="Close chat"
></cds-aichat-launcher>
```
