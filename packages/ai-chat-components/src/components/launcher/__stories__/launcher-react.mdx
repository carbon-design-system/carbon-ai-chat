## Overview

The `<Launcher>` React wrapper renders the `cds-aichat-launcher` web component and exposes the simple standalone launcher API for React applications.

### Getting started

```jsx
import Launcher from "@carbon/ai-chat-components/es/react/launcher.js";

function LauncherExample() {
  return <Launcher closedLabel="Open chat" openLabel="Close chat" />;
}
```
