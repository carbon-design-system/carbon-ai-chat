# Message item shell

[Source code](https://github.com/carbon-design-system/carbon-ai-chat/tree/main/packages/ai-chat-components/src/components/message-item-shell) &nbsp;|&nbsp; [Feedback](https://github.com/carbon-design-system/carbon-ai-chat/issues)

## Overview

Use `MessageItemShell` as the frame for one message row. It provides slots for the byline, content, attachments, and footer. It knows nothing about message data. This component is experimental, and its API may change without a deprecation window.

<Canvas of={Stories.Default} />

## Layout

Request and response rows use the same shell. Set `rowType` to `request` or `response` to choose the layout.

| Slot         | Region                                          |
| ------------ | ----------------------------------------------- |
| `byline`     | A `MessageByline`. Available on both row types. |
| default      | The message content.                            |
| `attachment` | File upload status.                             |
| `footer`     | Footer content from the host.                   |

The shell adds no screen reader announcements. Your slotted content decides what is announced, including file upload status.

The `byline`, `attachment`, and `footer` areas take no space while their slot is empty. A slot is empty when it holds no element and no non-blank text. A forwarded `<slot>` with nothing assigned counts as empty.

In a request row, the content, attachments, and footer share one column, so the footer's leading edge lines up with the content's.

## Custom properties

| Custom property | Default | Effect |
| --- | --- | --- |
| `--cds-aichat-message-item-shell-inset-start` | `$spacing-09` | Start padding of the row body, on both row types. A response ignores it when `hideAvatar` is set. |
| `--cds-aichat-message-item-shell-gap-block-start` | `$spacing-02` | Space between a response's byline and its content. Applies to a response with a byline only. |
| `--cds-aichat-message-item-shell-byline-gap-before` | `28px` | Space above the byline, which separates the row from the one before it. Applies to a row with a byline only. Set it to `0` to remove the gap. |

```jsx
<MessageItemShell
  rowType="response"
  style={{ '--cds-aichat-message-item-shell-inset-start': '1rem' }}>
  <div>Content</div>
</MessageItemShell>
```

## Examples

### Full width

Set `fullWidth` to break the content out of the inset column.

```jsx
import MessageItemShell from '@carbon/ai-chat-components/es/react/message-item-shell.js';

function Row() {
  return (
    <MessageItemShell rowType="response" fullWidth>
      <div>Wide content</div>
    </MessageItemShell>
  );
}
```

<Canvas of={Stories.FullWidth} />

### Hidden avatar

Set `hideAvatar` to hide the avatar in the byline. The label and timestamp remain visible.

Slot a `MessageByline` in `byline` and give its avatar `slot="avatar"` directly. The shell sets `hidden` on that avatar, and the byline then renders no avatar box. An avatar nested inside another element is not hidden.

```jsx
import MessageByline from '@carbon/ai-chat-components/es/react/message-byline.js';
import MessageItemShell from '@carbon/ai-chat-components/es/react/message-item-shell.js';
import UserAvatar from '@carbon/ai-chat-components/es/react/user-avatar.js';

function Row() {
  return (
    <MessageItemShell rowType="response" hideAvatar>
      <MessageByline slot="byline" label="Assistant" timestamp="10:42 AM">
        <UserAvatar slot="avatar" name="Assistant" />
      </MessageByline>
      <div>Content</div>
    </MessageItemShell>
  );
}
```
