# Message item shell

[Source code](https://github.com/carbon-design-system/carbon-ai-chat/tree/main/packages/ai-chat-components/src/components/message-item-shell) &nbsp;|&nbsp; [Feedback](https://github.com/carbon-design-system/carbon-ai-chat/issues)

## Overview

Use `MessageItemShell` as the frame for one message row. It provides slots for the byline, content, attachments, and footer. It knows nothing about message data. This component is experimental, and its API may change without a deprecation window.

<Canvas of={Stories.Default} />

## Layout

Request and response rows use the same shell. Set `rowType` to `request` or `response` to choose the layout.

| Slot         | Region                                                    |
| ------------ | --------------------------------------------------------- |
| `byline`     | Name, timestamp, and avatar. Available on both row types. |
| default      | The message content.                                      |
| `attachment` | File upload status.                                       |
| `footer`     | Footer content from the host.                             |

## Examples

### Full width

Set `fullWidth` to break the content out of the inset column.

```jsx
import MessageItemShell from '@carbon/ai-chat-components/es/react/message-item-shell.js';

function Row() {
  return (
    <MessageItemShell rowType="response" fullWidth>
      <div>Wide content</div>
    </MessageItemShell>
  );
}
```

<Canvas of={Stories.FullWidth} />

### Hidden avatar

Set `hideAvatar` to hide the avatar image within the byline. The name and timestamp remain visible.

```jsx
import MessageItemShell from '@carbon/ai-chat-components/es/react/message-item-shell.js';

function Row() {
  return (
    <MessageItemShell rowType="response" hideAvatar>
      <div slot="byline">
        <img
          className="cds-aichat-message-item-shell__byline-avatar"
          src="..."
          alt="Assistant"
        />
        Assistant 0:42 AM
      </div>
      <div>Content</div>
    </MessageItemShell>
  );
}
```
