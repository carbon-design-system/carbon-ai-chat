# Citation card

[Source code](https://github.com/carbon-design-system/carbon-ai-chat/tree/main/packages/ai-chat-components/src/components/conversational-search) &nbsp;|&nbsp; [Feedback](https://github.com/carbon-design-system/carbon-ai-chat/issues)

## Overview

Use `CitationCard` to show one source for a conversational search answer. Place cards in the shell's `citations` slot, usually inside a carousel.

<Canvas of={Stories.Default} />

## Variants

The card picks its variant from what you give it.

| You set | The card is | A click fires |
| --- | --- | --- |
| `url` | A link that opens in a new tab | `cds-aichat-citation-select`, then the browser follows the link |
| `expandable`, or the text overflows | A button | `cds-aichat-citation-expand`, then `cds-aichat-citation-select` |
| Neither, and the text fits | Static and not focusable | Nothing |

Focusing a link or button also fires `cds-aichat-citation-select`. The React wrapper exposes the events as `onCitationSelect` and `onCitationExpand`. A card with a `url` is never expandable. Pass only URLs you've validated.

### Expandable

Set `expandable` when you have more of the source to show, such as a full search result. Open your own view on `cds-aichat-citation-expand`.

<Canvas of={Stories.Expandable} />

### Plain

A short source with no URL stays static. The carousel still reaches it.

<Canvas of={Stories.Plain} />

### Overflowing text

The card measures its text whenever its size changes. Text longer than five lines makes it expandable. Widen the card and it's static again.

<Canvas of={Stories.Overflowing} />

### Markdown body

The `body` slot takes any block element, including `cds-aichat-markdown`. Use block elements in both slots, because the card can't measure inline ones. Keep links and buttons out of `body`, because the card's click target covers it.

<Canvas of={Stories.MarkdownBody} />
