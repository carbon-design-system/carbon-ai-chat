# Conversational search shell

[Source code](https://github.com/carbon-design-system/carbon-ai-chat/tree/main/packages/ai-chat-components/src/components/conversational-search) &nbsp;|&nbsp; [Feedback](https://github.com/carbon-design-system/carbon-ai-chat/issues)

## Overview

Use `ConversationalSearchShell` to lay out an answer, a citations toggle, and a citations region. Supply the answer in the default slot and sources in the `citations` slot.

<Canvas of={Stories.Default} />

## Layout and visibility

The shell owns spacing between the answer, toggle, and citations region. The region fills the available width up to 400px and fades in when opened. Reduced-motion preferences disable the fade.

`citationsOpen` controls the region's visibility. The shell hides closed citations while keeping your slotted content mounted. Your host can choose when to mount that content, load sources, or show a loading or error state.

The shell does not select citations or scroll them into view. Your host owns those actions, Markdown streaming, and answer highlights.

## Examples

### Open citations

Your host handles the toggle event, reads `event.detail.open`, and supplies the new `citationsOpen` value. The shell keeps its supplied state until your host updates it. The example leaves its citations mounted so the shell controls their visibility.

### Without a toggle

Hide the toggle when the answer has no citations.

### Highlighted answer

Supply Markdown with `==highlight==` spans to mark text tied to a selected citation. Your host owns the selection and updates the slotted Markdown.

### Streaming answer

Update the slotted Markdown as chunks arrive. Set `streaming` on the Markdown element; the shell does not change its slot content. Your host owns any error shown after an incomplete stream.

## Component API

The optional `answer-error` slot displays content after the toggle, outside the citations disclosure. Use it for answer errors that remain visible when citations close.

The `answer` CSS part wraps the answer and toggle. The chat uses this part to keep them aligned in narrow layouts.

Supply translated visible and accessible labels through `citationsLabel` and `toggleLabel`. The toggle event bubbles and crosses shadow roots. Read `event.detail.open` to handle opening and closing.
