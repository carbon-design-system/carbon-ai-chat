## Overview

Use `cds-aichat-autocomplete` to display contextual suggestions for user input.

The autocomplete component includes support for:

- **Flat Suggestions** - Simple list of suggestion items
- **Grouped Suggestions** - Organized suggestions with category headers
- **Rich Content** - Support for avatars and descriptions
- **Send/Select Suggestion** - When `disable-direct-send` is `false`, clicking an item sends directly to chat. When `true`, clicking inserts the item into the editor.
- **Header** - Optional header with custom title

### Getting started

Here's a quick example to get you started.

```html
<cds-aichat-autocomplete
  .items=${[
    { id: "1", label: "When is the best time to eat?" },
    { id: "2", label: "When is the sun rising today?" }
  ]}
  attached>
</cds-aichat-autocomplete>
```
