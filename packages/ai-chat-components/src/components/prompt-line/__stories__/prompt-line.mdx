## Overview

The prompt line is the chat input surface. It is composed of three web components:

- `<cds-aichat-prompt-line-shell>` — layout chrome: defines named slots and controls expanded/non-expanded modes.
- `<cds-aichat-prompt-line>` — the editor; starts as a plain textarea and upgrades to a Tiptap rich editor when `rich` is set or `extensions` are provided.
- `<cds-aichat-input-send-control>` — send button.

Optional components can be projected into slots:
- `<cds-aichat-toolbar>` → `message-actions` slot — icon action buttons.
- `<cds-aichat-autocomplete-controller>` → `autocomplete-content` slot — trigger-driven suggestion overlay.
- `<cds-aichat-file-uploads>` → `file-uploads` slot — uploaded file list.
