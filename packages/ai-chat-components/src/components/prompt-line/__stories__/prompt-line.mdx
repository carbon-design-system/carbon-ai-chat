## Overview

The prompt line is the chat input surface. It is composed of three web components:

- `<cds-aichat-prompt-line-shell>` — layout chrome: defines named slots and controls expanded/non-expanded modes.
- `<cds-aichat-prompt-line>` — the editor; starts as a plain textarea and upgrades to a Tiptap rich editor when `rich` is set or `extensions` are provided.
- `<cds-aichat-input-send-control>` — send button.

Optional components can be projected into slots:
- `<cds-aichat-toolbar>` → `message-actions` slot — icon action buttons.
- `<cds-aichat-autocomplete-controller>` → `autocomplete-content` slot — trigger-driven suggestion overlay.
- `<cds-aichat-file-uploads>` → `file-uploads` slot — uploaded file list.

## Expanded

The `expanded` attribute on the shell places the editor on its own full-width row, with the action toolbar and send button on a second row beneath it.

## Commands and mentions

Type `@` anywhere in the message to open a mention picker. Type `/` at the start of a line to open a command picker. Both use `buildCarbonExtensions` to register Tiptap plugins and `<cds-aichat-autocomplete-controller>` to manage the overlay lifecycle.

<Canvas of={PromptLineStories.CommandsAndMentions} />

## Conversation starters

Starter prompts appear automatically when the editor is empty and focused. A toggle action button enables or disables the starters list. The `renderCustomList` hook wraps `<cds-aichat-autocomplete>` to add the "Prompt suggestions" header.

<Canvas of={PromptLineStories.ConversationStarters} />

## File uploads

An attach button opens a native file picker. Selected files appear in the uploads row with a simulated progress animation (uploading → success). Uses `<cds-aichat-file-uploads>` in the `file-uploads` slot.

<Canvas of={PromptLineStories.FileUploads} />

## Typeahead

Live autocomplete: suggestions filter on every keystroke. Uses `buildCarbonExtensions({ autocomplete })` and `<cds-aichat-autocomplete-controller>` with no trigger character.
