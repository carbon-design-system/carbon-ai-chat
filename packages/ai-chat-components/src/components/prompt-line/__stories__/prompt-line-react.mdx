## Overview

The prompt line is the chat input surface. It is composed of three React components:

- `<PromptLineShell>` — layout chrome: defines named slots and controls expanded/non-expanded modes.
- `<PromptLine>` — the editor; starts as a plain textarea and upgrades to a Tiptap rich editor when `rich` is set or `extensions` are provided.
- `<CDSAIChatInputSendControl>` — send button.

Optional components can be projected into slots:
- `<Toolbar>` → `message-actions` slot — icon action buttons.
- `useChatAutocomplete` hook — manages trigger-driven suggestion overlays; return value is placed into the `autocomplete-content` slot.
- `<CDSAIChatFileUploads>` → `file-uploads` slot — uploaded file list.
