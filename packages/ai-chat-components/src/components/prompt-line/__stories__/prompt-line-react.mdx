## Overview

The prompt line is the **input interface component for the chat**. It provides the editing surface where users compose and send messages. It scales from a simple text input up to a rich editor with autocomplete suggestions, context chips, file attachments, and custom extensions.

The prompt line supports:

- **Text input** — text entry with placeholder, disabled, and autofocus states.
- **Autocomplete** — trigger-driven suggestion overlays via `useChatAutocomplete` and the `buildCarbonExtensions` helper.
- **Message actions** — icon action buttons projected into the `message-actions` slot (e.g. attach file, switch mode).
- **File uploads** — a visual file chip list projected into the `file-uploads` slot via `<CDSAIChatFileUploads>`.
- **Context chips** — inline token chips rendered inside the rich editor (e.g. `@mention`, `/command`).
- **Error state** — displays error message `field-messaging` slot and applies error styling.

It composes three React components into a complete input surface:

- `<PromptLineShell>` - layout chrome that defines named slots and controls inline/expanded layout modes.
- `<PromptLine>` — the editing surface; renders a plain `<textarea>` or a Tiptap rich-text editor with additional capabilities (context chips, custom Tiptap nodes, etc.) when `extensions` are provided.
- `<CDSAIChatInputSendControl>` — renders the send button or stop streaming button.

Additional components used with the prompt line:

- `<CDSAIChatAutocomplete>` - suggestion list overlay rendered by the `useChatAutocomplete` hook in the `autocomplete-content` slot.
- `<CDSAIChatFileUploads>` — container of file attachment chips rendered in the `file-uploads` slot.
- `<CDSAIChatErrorMessage>` — error message rendered in the `field-messaging` slot.

### Getting started

Here's a minimal implementation.

```jsx
import { useState, useCallback } from 'react';
import PromptLine from '@carbon/ai-chat-components/es/react/prompt-line.js';
import PromptLineShell from '@carbon/ai-chat-components/es/react/prompt-line-shell.js';
import CDSAIChatInputSendControl from '@carbon/ai-chat-components/es/react/input-send-control.js';

function ChatInput() {
  const [hasValidInput, setHasValidInput] = useState(false);

  const handleChange = useCallback((e) => {
    setHasValidInput(e.detail.rawValue.length > 0);
  }, []);

  const handleSend = useCallback(() => {
    // submit the message
  }, []);

  return (
    <PromptLineShell rounded>
      <PromptLine
        slot="editor"
        placeholder="Ask a question..."
        onChange={handleChange}
        onSendIntent={handleSend}
      />
      <CDSAIChatInputSendControl
        slot="send-control"
        hasValidInput={hasValidInput}
        onSend={handleSend}
      />
    </PromptLineShell>
  );
}
```

### Using with autocomplete

```jsx
import { useState, useCallback, useMemo, useRef } from 'react';
import PromptLine from '@carbon/ai-chat-components/es/react/prompt-line.js';
import PromptLineShell from '@carbon/ai-chat-components/es/react/prompt-line-shell.js';
import CDSAIChatInputSendControl from '@carbon/ai-chat-components/es/react/input-send-control.js';
import { useChatAutocomplete } from '@carbon/ai-chat-components/es/react/hooks/useChatAutocomplete.js';
import { buildCarbonExtensions } from '@carbon/ai-chat-components/es/components/prompt-line/index.js';

const ALL_ITEMS = [
  { id: '1', label: 'Summarize this document' },
  { id: '2', label: 'Translate to Spanish' },
  { id: '3', label: 'Write a follow-up email' },
];

function ChatInput() {
  const promptLineRef = useRef(null);
  const [hasValidInput, setHasValidInput] = useState(false);

  const autocomplete = useMemo(
    () => ({
      items: (query) =>
        ALL_ITEMS.filter((i) =>
          i.label.toLowerCase().includes(query.toLowerCase())
        ),
    }),
    []
  );

  const extensions = useMemo(
    () => buildCarbonExtensions({ autocomplete }),
    [autocomplete]
  );

  const { onTriggerChange, autocompleteContent } = useChatAutocomplete({
    autocomplete,
    promptLineRef,
  });

  const handleChange = useCallback((e) => {
    setHasValidInput(e.detail.rawValue.length > 0);
  }, []);

  return (
    <PromptLineShell rounded expanded>
      <PromptLine
        ref={promptLineRef}
        slot="editor"
        placeholder="Ask a question..."
        rich
        extensions={extensions}
        onChange={handleChange}
        onTriggerChange={onTriggerChange}
      />
      {autocompleteContent}
      <CDSAIChatInputSendControl
        slot="send-control"
        hasValidInput={hasValidInput}
        onSend={() => { /* submit */ }}
      />
    </PromptLineShell>
  );
}
```

### Using with file uploads

```jsx
import { useState, useCallback, useRef } from 'react';
import PromptLine from '@carbon/ai-chat-components/es/react/prompt-line.js';
import PromptLineShell from '@carbon/ai-chat-components/es/react/prompt-line-shell.js';
import CDSAIChatInputSendControl from '@carbon/ai-chat-components/es/react/input-send-control.js';
import CDSAIChatFileUploads from '@carbon/ai-chat-components/es/react/file-uploads.js';
import { FileStatusValue } from '@carbon/ai-chat-components/es/components/prompt-line/index.js';

function ChatInput() {
  const fileInputRef = useRef(null);
  const [uploads, setUploads] = useState([]);
  const [hasValidInput, setHasValidInput] = useState(false);

  const handleAttachClick = useCallback(() => {
    fileInputRef.current?.click();
  }, []);

  const handleFileSelected = useCallback((e) => {
    const files = Array.from(e.target.files ?? []);
    e.target.value = ''; // reset so re-selecting the same file fires `change`
    const newUploads = files.map((file) => ({
      id: `file-${Date.now()}-${Math.random().toString(36).slice(2)}`,
      file,
      status: FileStatusValue.EDIT,
    }));
    setUploads((prev) => [...prev, ...newUploads]);
  }, []);

  const handleFileRemove = useCallback((e) => {
    setUploads((prev) => prev.filter((u) => u.id !== e.detail.fileId));
  }, []);

  const hasValidInputOrUploads =
    hasValidInput || uploads.some((u) => !u.isError);

  return (
    <PromptLineShell rounded expanded>
      {/* Always mounted so live regions persist after the last file is removed */}
      <CDSAIChatFileUploads
        slot="file-uploads"
        uploads={uploads}
        onFileRemove={handleFileRemove}
      />
      <PromptLine
        slot="editor"
        placeholder="Ask a question..."
        onChange={(e) => setHasValidInput(e.detail.rawValue.length > 0)}
      />
      <div slot="message-actions">
        <input
          ref={fileInputRef}
          type="file"
          multiple
          tabIndex={-1}
          hidden
          onChange={handleFileSelected}
        />
        <cds-icon-button
          size="sm"
          kind="ghost"
          align="top-start"
          onClick={handleAttachClick}>
          {/* attach icon */}
          <span slot="tooltip-content">Attach file</span>
        </cds-icon-button>
      </div>
      <CDSAIChatInputSendControl
        slot="send-control"
        hasValidInput={hasValidInputOrUploads}
        onSend={() => { /* submit */ }}
      />
    </PromptLineShell>
  );
}
```

## Component API

### PromptLineShell

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `rounded` | `boolean` | `false` | Applies rounded corners to the shell border. |
| `expanded` | `boolean` | `false` | Expanded layout: the editor fills its own full-width row; message actions and send control move to a second row beneath it. |
| `hasError` | `boolean` | `false` | Puts the shell into the error state (red border treatment). |
| `disabled` | `boolean` | `false` | Disables the shell and all slotted content. |

### PromptLine

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `placeholder` | `string` | `''` | Placeholder text shown when the surface is empty. |
| `disabled` | `boolean` | `false` | Disables editing. Surface stays mounted but non-editable. |
| `rich` | `boolean` | `false` | Upgrades the surface to the Tiptap rich editor (lazy-loaded). Required for autocomplete / mentions / commands. |
| `extensions` | `Extension[]` | `[]` | Host-supplied Tiptap extensions appended to the Carbon bundle. Memoize this array — a reference change recreates the editor. |
| `content` | `JSONContent \| string` | — | Initial or controlled content. |
| `ariaLabel` | `string` | `''` | Accessible label for the editing surface. |
| `autofocus` | `boolean` | `false` | Focus the surface on mount. |

### CDSAIChatInputSendControl

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `hasValidInput` | `boolean` | `false` | Enables the send button and switches to the filled send icon. |
| `disabled` | `boolean` | `false` | Disables the entire control. |
| `disableSend` | `boolean` | `false` | Disables only the send button (independent of `disabled`). |
| `showStopStreaming` | `boolean` | `false` | Swaps the send button for the stop-streaming button. |
| `disableStopStreaming` | `boolean` | `false` | Disables the stop-streaming button. |
| `buttonLabel` | `string` | `'Send'` | Tooltip label for the send button. |
| `stopResponseLabel` | `string` | `'Stop response'` | Tooltip label for the stop-streaming button. |

### CDSAIChatErrorMessage

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `title` | `string` | `''` | Short error title text. |
| `description` | `string` | `''` | Optional longer description shown below the title. |
| `collapsible` | `boolean` | `false` | Whether the description can be toggled via a chevron button. |
| `fullscreen` | `boolean` | `false` | Switches to the fullscreen layout (warning icon moves to the end of the row). |

### CDSAIChatAutocomplete

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `SuggestionItem[]` | `[]` | Flat list of suggestion items to display. |
| `groups` | `SuggestionItemGroup[]` | `[]` | Grouped suggestion items displayed after any flat `items`. |
| `headerConfig` | `HeaderConfig` | — | Optional header rendered above the suggestion list (`{ showHeader, title }`). |
| `i18n` | `AutocompleteI18n` | `defaultAutocompleteI18n` | Localized strings for announcements and the listbox label. |
| `inputText` | `string` | `''` | The text already typed by the user; used to highlight the matching prefix in each item. |
| `enableSendButton` | `boolean` | `true` | Shows a send button inside each suggestion item. |
| `attached` | `boolean` | `true` | When `true`, suppresses bottom corner rounding (use when overlaying the input). |

### CDSAIChatFileUploads

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `uploads` | `FileUpload[]` | `[]` | Array of file upload objects to display. Each item must have `id`, `file`, and `status` (`FileStatusValue`). |
| `removeFileLabel` | `string` | `'Remove file'` | Accessible label for the remove button on each file chip. |
| `uploadingFileLabel` | `string` | `'Uploading file'` | Label shown while a file is uploading. |
| `fileRemovedLabel` | `string` | `'File removed.'` | Screen-reader announcement when a file is removed. |
| `uploadSuccessLabel` | `string` | `'The file was uploaded successfully.'` | Screen-reader announcement on upload success. |
| `uploadFailureLabel` | `string` | `'There was an error uploading the file.'` | Screen-reader announcement on upload failure. |
| `getFilesAddedText` | `(args: { count: number }) => string` | English default | Returns the announcement when one or more files are staged. Override for localization or pluralization. |
| `getFilesUploadingText` | `(args: { count: number }) => string` | English default | Returns the announcement when one or more files begin uploading. Override for localization or pluralization. |
