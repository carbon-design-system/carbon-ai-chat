## Overview

The prompt line is the chat input surface. It is composed of three React components:

- `<PromptLineShell>` — layout chrome: defines named slots and controls expanded/non-expanded modes.
- `<PromptLine>` — the editor; starts as a plain textarea and upgrades to a Tiptap rich editor when `rich` is set or `extensions` are provided.
- `<CDSAIChatInputSendControl>` — send button.

Optional components can be projected into slots:
- `<Toolbar>` → `message-actions` slot — icon action buttons.
- `useChatAutocomplete` hook — manages trigger-driven suggestion overlays; return value is placed into the `autocomplete-content` slot.
- `<CDSAIChatFileUploads>` → `file-uploads` slot — uploaded file list.

## Expanded

The `expanded` prop on the shell places the editor on its own full-width row, with the action toolbar and send button on a second row beneath it.

## Commands and mentions

Type `@` anywhere in the message to open a mention picker. Type `/` at the start of a line to open a command picker. Both use `buildCarbonExtensions` to register Tiptap plugins and the `useChatAutocomplete` hook to manage the overlay.

<Canvas of={PromptLineReactStories.CommandsAndMentions} />

## Conversation starters

Starter prompts appear automatically when the editor is empty and focused. A toggle action button enables or disables the starters list. The `renderCustomList` hook wraps `<CDSAIChatAutocomplete>` to add the "Prompt suggestions" header.

<Canvas of={PromptLineReactStories.ConversationStarters} />

## File uploads

An attach button opens a native file picker. Selected files appear in the uploads row with a simulated progress animation (uploading → success). Uses `<CDSAIChatFileUploads>` in the `file-uploads` slot.

<Canvas of={PromptLineReactStories.FileUploads} />

## Typeahead

Live autocomplete: suggestions filter on every keystroke. Uses `buildCarbonExtensions({ autocomplete })` and the `useChatAutocomplete` hook with no trigger character.
