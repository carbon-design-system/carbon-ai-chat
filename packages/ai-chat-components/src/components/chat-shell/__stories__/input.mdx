## Overview

Use [Prompt line shell](?path=/docs/preview-prompt-line--overview) in the `slot="input"` of `cds-aichat-shell` to compose a full input area. The prompt line shell has two layouts: compact (single row) and expanded (with an actions row beneath it). It exposes named slots for `editor`, `message-actions`, `file-uploads`, `autocomplete-content`, `field-messaging`, and `send-control`.

### Getting started

Here's a quick example to get you started.

```html
<cds-aichat-shell>
  <div slot="header">Chat Header</div>
  <div slot="messages">Messages</div>

  <cds-aichat-prompt-line-shell slot="input">
    <cds-aichat-prompt-line
      slot="editor"
      placeholder="Ask a question"></cds-aichat-prompt-line>
    <cds-aichat-input-send-control slot="send-control" button-label="Send">
    </cds-aichat-input-send-control>
  </cds-aichat-prompt-line-shell>
</cds-aichat-shell>
```

### Expanded layout with message actions

```html
<cds-aichat-shell>
  <div slot="header">Chat Header</div>
  <div slot="messages">Messages</div>

  <cds-aichat-prompt-line-shell slot="input" expanded>
    <cds-aichat-prompt-line
      slot="editor"
      placeholder="Ask a question"></cds-aichat-prompt-line>

    <!-- slot="message-actions" content appears at the start of the actions row -->
    <div slot="message-actions">
      <cds-icon-button size="sm" kind="ghost">
        <svg slot="icon"><!-- icon --></svg>
        <span slot="tooltip-content">Summarize</span>
      </cds-icon-button>
    </div>

    <cds-aichat-input-send-control slot="send-control" button-label="Send">
    </cds-aichat-input-send-control>
  </cds-aichat-prompt-line-shell>
</cds-aichat-shell>
```
