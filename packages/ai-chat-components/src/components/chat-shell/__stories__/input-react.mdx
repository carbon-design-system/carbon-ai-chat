## Overview

Use [Prompt line shell](?path=/docs/preview-prompt-line--overview) in the `slot="input"` of `ChatShell` to compose a full input area. The prompt line shell has two layouts: compact (single row) and expanded (with an actions row beneath it). It exposes named slots for `editor`, `message-actions`, `file-uploads`, `autocomplete-content`, `field-messaging`, and `send-control`.

### Getting started

Here's a quick example to get you started.

```jsx
import ChatShell from '@carbon/ai-chat-components/es/react/chat-shell.js';
import PromptLine from '@carbon/ai-chat-components/es/react/prompt-line.js';
import PromptLineShell from '@carbon/ai-chat-components/es/react/prompt-line-shell.js';
import CDSAIChatInputSendControl from '@carbon/ai-chat-components/es/react/input-send-control.js';

function ChatInput() {
  const [hasValidInput, setHasValidInput] = React.useState(false);

  return (
    <ChatShell>
      <div slot="header">Chat Header</div>
      <div slot="messages">Messages</div>

      <PromptLineShell slot="input">
        <PromptLine
          slot="editor"
          placeholder="Ask a question"
          onChange={(e) => setHasValidInput(e.detail.rawValue.length > 0)}
        />
        <CDSAIChatInputSendControl
          slot="send-control"
          hasValidInput={hasValidInput}
          buttonLabel="Send"
          onSend={() => console.log('send')}
        />
      </PromptLineShell>
    </ChatShell>
  );
}
```

### Expanded layout with message actions

```jsx
function ChatInputExpanded() {
  const [hasValidInput, setHasValidInput] = React.useState(false);

  return (
    <ChatShell>
      <div slot="header">Chat Header</div>
      <div slot="messages">Messages</div>

      <PromptLineShell slot="input" expanded>
        <PromptLine
          slot="editor"
          placeholder="Ask a question"
          onChange={(e) => setHasValidInput(e.detail.rawValue.length > 0)}
        />

        <div slot="message-actions">
          <cds-icon-button size="sm" kind="ghost">
            <svg slot="icon" />
            <span slot="tooltip-content">Summarize</span>
          </cds-icon-button>
        </div>

        <CDSAIChatInputSendControl
          slot="send-control"
          hasValidInput={hasValidInput}
          buttonLabel="Send"
          onSend={() => console.log('send')}
        />
      </PromptLineShell>
    </ChatShell>
  );
}
```
