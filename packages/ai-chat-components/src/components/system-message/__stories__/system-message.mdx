# System message

[Source code](https://github.com/carbon-design-system/carbon-ai-chat/tree/main/packages/ai-chat-components/src/components/system-message) &nbsp;|&nbsp; [Feedback](https://github.com/carbon-design-system/carbon-ai-chat/issues)

## Overview

Use `cds-aichat-system-message` for a status line between messages. This element is experimental, and its API may change without a deprecation window.

<Canvas of={Stories.Default} />

## Key features

- **Standalone**: The message adds its own outer spacing by default. Set the `standalone` property to `false` when it sits inside a message bubble, which owns the spacing.
- **Divider**: Set the boolean `divider` attribute to draw a line above the text.
- **Response stopped**: Set the boolean `response-stopped` attribute to render the message in the "response stopped" indicator styling.
- **Optional icon**: Set the `icon` property to a `@carbon/icons` icon to show it before the text.
- **Text-only slot**: Put the text in the default slot.

## Examples

### With a divider

```html
<cds-aichat-system-message divider>
```

## Accessibility

The host element gets `role="status"` unless you set a role yourself. That role already announces changes politely, so the element adds no `aria-live` attribute. The icon is decorative and hidden from assistive technology, so the text must carry the full meaning.
